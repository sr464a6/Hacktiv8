# Hacktiv8

A project developed for the **IBM SkillsBuild Hackathon**.

## About

Hacktiv8 is a project repository containing the applications, tools, resources, and supporting files needed for the IBM SkillsBuild Hackathon.

## Project

This repository is used to develop, test, and manage the project throughout the hackathon.

## Tech & Tools

* IBM SkillsBuild
* IBM Bob
* Langflow
* AI & Automation Tools

## Getting Started

Clone the repository:

```bash
git clone https://github.com/sr464a6/Hacktiv8.git
cd Hacktiv8
```

Follow the instructions and setup files provided in the repository to run the project.
